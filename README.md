## 目录约定

每个系列一个文件夹，内部结构自定，建议：

```
<series>/
├── README.md      # 系列介绍 + 期数索引 / 路线图
├── episodes/      # 每期正文（Markdown）
├── answers/       # 思考题答案（如有，下期开头公布）
└── covers/        # 封面图归档
```

## 发布记录

所有系列统一记在 [publish-log.md](publish-log.md)，包含标题、摘要、草稿 media_id 与发布 URL。
